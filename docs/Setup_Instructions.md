# Setup instructions

**JDK version used:** OpenJDK 21.0.12 (Java 21).

1. Install JDK 21 and configure it in your IDE or `JAVA_HOME`.
2. Run `java -version` and `javac -version` to check that Java and its compiler are available.
3. Create a Hello World file:

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

4. Compile: `javac HelloWorld.java` and run: `java HelloWorld`.

Expected output:
```text
Hello, World!
```

5. For LearnTrack, follow the compile/run commands in the root [README](../README.md).
